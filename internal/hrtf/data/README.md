# CIPIC subject 003 HRIR dataset

`cipic_subject_003.hrtf` is a compact conversion of `subject_003.sofa` from
the CIPIC HRTF Database 1.1 (Center for Image Processing and Integrated
Computing, University of California, Davis).

- Source: <https://www.sofacoustics.org/data/database/cipic/subject_003.sofa>
- Original dataset: CIPIC HRTF Database, Release 1.1 (2001), UC Regents.
- Conversion format: 1250 measurements, 2 receivers, 200 taps, 44.1 kHz,
  float32 interleaved as described in `internal/hrtf/dataset.go`.
- The data is used under the CIPIC/UC Regents terms; see
  `LICENSE-CIPIC.txt`.
- If you replace this file, keep the same header/layout and update the
  attribution above.
